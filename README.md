\# Healthcare Analysis Dashboard



\## Project Overview

An interactive healthcare analytics dashboard created using Microsoft Power BI to explore healthcare data and highlight key trends and performance indicators.



\## Tools \& Technologies

\- Microsoft Power BI

\- Power Query

\- DAX

\- Data Cleaning

\- Data Visualization



\## Key Analysis Areas

\- Healthcare performance indicators

\- Patient and service trends

\- Comparisons across categories

\- Key patterns and insights from the data
